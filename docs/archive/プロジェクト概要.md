### コアコンセプト

パターン・ランゲージとは、ある領域の「よい実践」の背後にある「コツ」を抽出し、再利用可能な形式で記述した知識体系。
このアプリは、そのパターン群を **「本として体系的に読む」** か **「知恵として横断的に引く」** かの2つの読み方を提供する。

## 4. コンテンツ概要

### 2つの言語（Language）

| 言語 | パターン数 | テーマカラー | 特徴 |
|------|-----------|-------------|------|
| **楽天主義実践パターン** | 30件 | `#ff6b35`（オレンジ） | 仕事・ビジネスの実践知 |
| **燕市まちづくりパターン** | 21件 | `#10b981`（エメラルドグリーン） | 地域コミュニティの実践知 |
| **合計** | **51件** | — | — |

### パターンのデータ構造

```typescript
{
  id: number,           // 1〜N（Language内の連番）
  pattern_name: string, // パターン名
  intro?: string,       // 一言の導入文（任意）
  context: string,      // 「▼その状況において」
  problem: string,      // 「しかし〜」
  solution: string,     // 「▼そこで」（最重要）
  consequence?: string, // 「▼その結果」（任意）
  tags?: string[]       // タグ（任意・将来のフィルタ機能用）
}
```

### イラストファイルの命名規則

```
assets/illustrations/{language_id}/{番号}_{パターン名}.png
```

## 5. デザインシステム：Neo Brutalism（Mono）

**採用理由：** 情報が直感的に伝わる明快さ、アニメーションとの相性、シンプルなルールによる拡張性

### 基本ルール

| ルール | 仕様 |
|--------|------|
| 背景色 | `#FFFFFF`（純白） |
| テキスト | `#000000`（純黒） |
| アクセント | 各Languageのテーマカラー / Pattern Viewは `#2563eb`（青） |
| ボーダー | 2-3px solid black |
| 角丸 | **0px**（使わない） |
| シャドウ | ハードシャドウ（blur無し、offset 6-12px） |
| アニメーション | 全インタラクティブ要素に **必須** |

### アニメーション標準設定

```typescript
// スプリング物理（カード系）
{ type: "spring", stiffness: 400, damping: 15 }

// ホバー
scale: 1.02, y: -2, shadow: 12px offset

// タップ
scale: 0.98, shadow: 4px offset
```

### 禁止事項

- ❌ ドロップシャドウ（blur系）
- ❌ グラデーション
- ❌ 薄いグレーの文字
- ❌ border-radius をカード・ボタンに使う
- ❌ アニメーションなしのインタラクティブ要素

## 11. 開発ルール・注意事項

### デプロイフロー

```bash
git add .
git commit -m "変更内容のメッセージ"
git push
# → Vercelが自動でビルド・デプロイ
```

### 新しいLanguageを追加する手順

1. `assets/{language_id}_patterns.json` を作成（JSONスキーマは §4 参照）
2. `assets/illustrations/{language_id}/` にイラスト配置
3. `src/data/languages.ts` に言語メタデータを追加
4. git push → 自動デプロイ

### コーディング規約

- TypeScript strict mode を維持する
- 新規コンポーネントは `src/components/` に配置
- アニメーションは必ずスプリング物理を使用（transitionではなくspringを優先）
- インタラクティブ要素（ボタン・カード）には必ずホバー・タップアニメーションを追加
- Neo Brutalismの禁止事項を守る（§5 参照）
